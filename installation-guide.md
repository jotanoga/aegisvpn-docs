# AegisVPN Installation Guide

**Version:** 1.0  
**Last updated:** July 10, 2026

---

# Overview

This guide explains how to install **AegisVPN** on supported devices.

After completing the installation, you'll be ready to establish your first secure VPN connection and start protecting your online privacy.

---

# Supported Platforms

AegisVPN supports the following operating systems:

- Windows 10 or later
- macOS 12 (Monterey) or later
- Ubuntu 22.04 LTS or later
- Android 10 or later
- iOS 16 or later

---

# System Requirements

## Windows

- Windows 10 or newer
- 200 MB available storage
- Stable Internet connection
- Administrator privileges

## macOS

- macOS Monterey or newer
- 200 MB available storage
- Internet connection

## Linux

- Ubuntu 22.04 LTS or newer
- sudo privileges
- Internet connection

## Mobile Devices

- Android 10+
- iOS 16+
- Internet connection

---

# Before You Begin

Before installing AegisVPN, verify that:

- Your operating system is supported.
- Your device has sufficient available storage.
- You have a stable Internet connection.
- You have an active AegisVPN account.

If you don't have an account yet, create one before continuing.

---

# Download AegisVPN

1. Open your web browser.
2. Visit the AegisVPN website.
3. Navigate to **Downloads**.
4. Select your operating system.
5. Download the latest installation package.

> **Note**
>
> Always download AegisVPN from the official website to ensure the installer is authentic and up to date.

---

# Install AegisVPN on Windows

1. Double-click the downloaded installer.
2. If prompted by User Account Control, select **Yes**.
3. Accept the License Agreement.
4. Choose the installation folder.
5. Select **Install**.
6. Wait for the installation to complete.
7. Select **Launch AegisVPN**.
8. Click **Finish**.

---

# Install AegisVPN on macOS

1. Open the downloaded **.dmg** file.
2. Drag **AegisVPN** into the **Applications** folder.
3. Open the **Applications** folder.
4. Launch AegisVPN.
5. If macOS displays a security warning, allow the application from:

**System Settings → Privacy & Security**

---

# Install AegisVPN on Ubuntu

1. Open Terminal.
2. Navigate to the download directory.

```bash
cd ~/Downloads
```

3. Install the package.

```bash
sudo dpkg -i aegisvpn.deb
```

4. Install missing dependencies if required.

```bash
sudo apt install -f
```

5. Launch AegisVPN from the Applications menu.

---

# Install AegisVPN on Android

1. Open Google Play.
2. Search for **AegisVPN**.
3. Tap **Install**.
4. Wait until installation finishes.
5. Open the application.

---

# Install AegisVPN on iPhone or iPad

1. Open the App Store.
2. Search for **AegisVPN**.
3. Tap **Get**.
4. Authenticate using Face ID, Touch ID or your password.
5. Launch the application.

---

# Sign In

1. Open AegisVPN.
2. Enter your email address.
3. Enter your password.
4. Select **Sign In**.

If Multi-Factor Authentication (MFA) is enabled, complete the verification process.

---

# Verify the Installation

After signing in, verify that:

- The application opens normally.
- Your subscription status is displayed.
- The server list loads correctly.
- The **Connect** button is available.

To verify the VPN connection:

1. Click **Connect**.
2. Wait until the status changes to **Connected**.
3. Open your browser.
4. Visit an IP lookup website.
5. Confirm that your public IP address has changed.

---

# Update AegisVPN

AegisVPN checks for updates automatically.

To perform a manual update:

1. Open **Settings**.
2. Select **About**.
3. Click **Check for Updates**.

Install all available updates to ensure maximum security and performance.

---

# Uninstall AegisVPN

## Windows

1. Open **Settings**.
2. Go to **Apps**.
3. Select **AegisVPN**.
4. Click **Uninstall**.

## macOS

1. Open **Applications**.
2. Drag **AegisVPN** to the Trash.
3. Empty the Trash.

## Ubuntu

```bash
sudo apt remove aegisvpn
```

## Mobile Devices

Uninstall the application using your device's standard app removal process.

# Common Installation Issues

## The installer won't launch

### Possible causes

- Corrupted download
- Antivirus interference
- Insufficient permissions

### Resolution

- Download the installer again.
- Run the installer as Administrator.
- Temporarily disable antivirus software if necessary.

---

## The application won't open

### Possible causes

- Unsupported operating system
- Incomplete installation

### Resolution

- Restart your device.
- Reinstall AegisVPN.
- Verify that your operating system meets the minimum requirements.

---

## Unable to sign in

### Possible causes

- Incorrect credentials
- Internet connectivity issues

### Resolution

- Reset your password.
- Verify your Internet connection.
- Try signing in again.
