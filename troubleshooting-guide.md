# AegisVPN Troubleshooting Guide

**Version:** 1.0  
**Last updated:** July 10, 2026

---

# Overview

This guide helps you identify and resolve the most common issues you may encounter while using AegisVPN.

For each issue, you'll find:

- Symptoms
- Possible causes
- Recommended solutions

If the problem persists after following the suggested steps, contact AegisVPN Support.

---

# Before You Begin

Before troubleshooting:

- Verify that you're using the latest version of AegisVPN.
- Restart your device.
- Confirm that your Internet connection is working.
- Ensure your subscription is active.

---

# Installation Issues

## The installer won't launch

### Possible causes

- Corrupted installer
- Antivirus software blocking the installation
- Insufficient permissions

### Resolution

1. Download the installer again.
2. Run it as Administrator.
3. Temporarily disable antivirus software if necessary.
4. Restart the installation.

---

## Installation fails

### Possible causes

- Insufficient disk space
- Unsupported operating system
- Missing system updates

### Resolution

1. Free up storage space.
2. Install the latest operating system updates.
3. Verify that your operating system is supported.
4. Download a new installation package.

---

# Connection Issues

## Unable to connect to a VPN server

### Possible causes

- Internet connection problems
- VPN server temporarily unavailable
- Firewall restrictions

### Resolution

1. Verify your Internet connection.
2. Connect to a different VPN server.
3. Restart AegisVPN.
4. Restart your device.
5. Temporarily disable your firewall to test the connection.

---

## Connection takes too long

### Possible causes

- High server load
- Poor network quality
- Long-distance server selection

### Resolution

- Choose a nearby server.
- Switch to WireGuard®.
- Restart your router.
- Try another Internet connection.

---

## VPN disconnects frequently

### Possible causes

- Unstable Internet connection
- Wi-Fi interruptions
- Network restrictions

### Resolution

- Use a wired connection whenever possible.
- Restart your router.
- Switch VPN protocol.
- Connect to another server.

---

# Login Issues

## Incorrect username or password

### Resolution

1. Verify your credentials.
2. Reset your password if necessary.
3. Ensure Caps Lock is disabled.

---

## Multi-Factor Authentication fails

### Resolution

- Check your device's date and time.
- Generate a new authentication code.
- Retry the login process.

---

# Performance Issues

## Slow Internet speed

### Possible causes

- Distant VPN server
- Server congestion
- Local network limitations

### Resolution

1. Connect to a nearby server.
2. Use WireGuard®.
3. Disconnect unnecessary devices from your network.
4. Test another VPN location.

---

## High latency while gaming

### Resolution

- Select the nearest available server.
- Close background downloads.
- Use a wired Ethernet connection.
- Switch to WireGuard®.

---

## Streaming buffers frequently

### Resolution

- Choose a nearby streaming server.
- Restart the streaming application.
- Clear your browser cache.
- Test another VPN location.

---

# Security Issues

## Kill Switch blocks Internet after disconnecting

### Explanation

This behavior is expected.

Kill Switch blocks Internet traffic until a secure connection is restored.

### Resolution

- Reconnect to the VPN.

or

- Disable Kill Switch temporarily from:

**Settings → Privacy & Security**

---

## DNS Leak Detected

### Resolution

1. Enable Secure DNS.
2. Disconnect.
3. Reconnect.
4. Test again using a DNS leak testing website.

---

## IP Address Does Not Change

### Possible causes

- VPN not connected
- Browser cache
- Split Tunneling configuration

### Resolution

- Disconnect and reconnect.
- Clear browser cache.
- Disable Split Tunneling temporarily.
- Test using another browser.

---

# Application Issues

## Application won't start

### Resolution

1. Restart your device.
2. Reinstall AegisVPN.
3. Update your operating system.

---

## Application freezes

### Resolution

- Force close the application.
- Restart the device.
- Install the latest version.

---

## Settings are not saved

### Possible causes

- Permission issues
- Corrupted configuration

### Resolution

1. Restart the application.
2. Restore default settings.
3. Reconfigure your preferences.

---

# Server Issues

## Selected server is unavailable

### Resolution

Choose another server in the same country.

Server availability may change due to maintenance or high demand.

---

## Cannot access local services

### Possible causes

- Connected to another country
- Geo-restrictions

### Resolution

Disconnect the VPN or connect to a server in your own country.

---

# Subscription Issues

## Subscription not detected

### Resolution

1. Sign out.
2. Sign back in.
3. Refresh your account information.
4. Verify your subscription on the website.

---

## Premium features unavailable

### Resolution

- Confirm that your subscription is active.
- Restart the application.
- Contact Support if the issue continues.

---

# Update Issues

## Update fails

### Resolution

1. Restart the application.
2. Download the latest installer manually.
3. Install the new version over the existing installation.

---

# Advanced Troubleshooting

If basic troubleshooting does not solve the issue:

1. Restart your device.
2. Reinstall AegisVPN.
3. Restore default settings.
4. Test using another network.
5. Update your operating system.
6. Contact Support.

---

# Collect Diagnostic Information

Before contacting Support, gather the following information:

- Operating system and version
- AegisVPN version
- Device model
- VPN protocol
- Selected server
- Error message (if available)
- Steps to reproduce the issue

Providing this information helps reduce resolution time.

---

# Contact Support

If you still cannot resolve the problem:

- Submit a support ticket.
- Attach screenshots if applicable.
- Include diagnostic information.
- Describe the issue in as much detail as possible.
