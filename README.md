
# AegisVPN Documentation

Technical documentation project for a fictional VPN service created as part of a Docs-as-Code and Technical Writing portfolio.

This repository demonstrates the creation, organization and maintenance of end-user technical documentation using industry-standard documentation practices, Markdown and Git-based workflows.

---

## Project Overview

AegisVPN is a fictional cybersecurity product designed to provide secure, private and unrestricted Internet access.

The documentation set covers the complete user journey, from installation and onboarding to advanced configuration, troubleshooting and self-service support.

The objective of this project is to showcase skills in:

- Technical Writing
- Documentation Architecture
- User Assistance Content
- Knowledge Base Development
- Information Design
- Docs-as-Code Workflows
- Markdown Authoring
- Git and GitHub Documentation Management
